# ignasipalauferrero.github.io

Portfolio de **Ignasi Palau Ferrero**, desarrollador full-stack en Barcelona.

🔗 **https://ignasipalauferrero.github.io**

La web presenta tres productos en desarrollo activo, con su estado real, su arquitectura y las decisiones técnicas detrás de cada uno:

| Proyecto | Qué es | Stack principal |
|---|---|---|
| [Beta 3M](https://ignasipalauferrero.github.io/proyectos/beta3m.html) | App de apuntes para tablet con lápiz e IA | React 19 · TypeScript · Tiptap · Canvas 2D · Node/Express · PostgreSQL |
| [GreenAPP](https://ignasipalauferrero.github.io/proyectos/greenapp.html) | App móvil de nutrición y entreno con marketplace de profesionales y gimnasios | React Native · Expo · Supabase · PostgreSQL/PostGIS · Edge Functions |
| [Sorella](https://ignasipalauferrero.github.io/proyectos/sorella.html) | Digitalización completa de un salón de belleza real | React · Vite · Tailwind · Python · FastAPI · MySQL · WhatsApp API |

El código de los tres proyectos es privado. Esta web no publica código, claves ni datos: las capturas son de las aplicaciones reales ejecutadas con datos de demostración.

## Cómo está hecha

HTML, CSS y JavaScript sin dependencias ni paso de build, servida con GitHub Pages. Tipografías autoalojadas (Bricolage Grotesque, Schibsted Grotesk y Caveat, licencia SIL OFL), tema claro y oscuro, adaptada a móvil.

```
index.html            portada
proyectos/*.html      un caso de estudio por proyecto
assets/css/site.css   estilos
assets/js/site.js     tema y visor de capturas
assets/img/           capturas en WebP
assets/fonts/         tipografías
```
